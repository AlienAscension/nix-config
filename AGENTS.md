# AGENTS.md

Personal NixOS + nix-darwin flake. Four NixOS hosts and one Mac, each built
from shared modules with Home Manager, Hyprland, and agenix secrets. There is
no CI and no test suite — the check is that the affected flake output builds.

## Repo map

| Path | Purpose |
|------|---------|
| `flake.nix` | Inputs + `nixosConfigurations.<host>` / `darwinConfigurations.macbook` |
| `lib/mksystem.nix` | Builds a NixOS system for `machines/<name>/` |
| `lib/mkdarwin.nix` | Builds the nix-darwin system for `machines/macbook/` |
| `machines/<host>/configuration.nix` | Per-host: hostname, hardware modules, user wiring |
| `machines/<host>/hardware.nix` | Generated by `nixos-generate-config` — don't hand-edit beyond UUIDs |
| `machines/<host>/secrets.nix` | Per-host agenix `age.secrets` declarations |
| `modules/system/default.nix` | Shared NixOS config (packages, services, overlays) |
| `modules/system/darwin.nix` | Shared macOS/nix-darwin config |
| `modules/home/*.nix` | Shared Home Manager config (cli, dev, editor, terminal, apps, hyprland, noctalia, linux-desktop, darwin) |
| `modules/hardware/*.nix` | CPU/GPU/bluetooth modules imported per machine |
| `users/linus/home.nix` | Home Manager entrypoint for NixOS hosts (`linus`) |
| `users/work/home.nix` | Scaffolded work user — not enabled by any machine yet |
| `users/lbr/home-darwin.nix` | Home Manager entrypoint for the Mac (`lbr`) |
| `secrets/*.age` | Encrypted secrets (intentionally committed) |
| `secrets.nix` | Agenix recipients: host SSH pubkeys per secret |
| `pkgs/` | Local derivations (`topf`, vendored `maintainer-list.nix`) |

Hosts: `desktop`, `laptop`, `geekom` (x86_64-linux), `vm-aarch64`
(aarch64-linux), `macbook` (aarch64-darwin, user `lbr`).

## Build / switch

```sh
nh os switch .            # NixOS: rebuild + switch (persistent)
nh os test .              # NixOS: rebuild + test (reverts on reboot)
nh os build .             # build only
nh os switch .#<host>     # pin the output when the hostname doesn't match

nh darwin switch .        # macbook (or: darwin-rebuild switch --flake .#macbook)
```

`nh` auto-detects the hostname. First build of `noctalia-greeter` compiles from
source (~10–30 min); the noctalia shell and other inputs come from Cachix.

## Where changes go

| Change | Where |
|--------|-------|
| CLI tool for a user | `modules/home/cli.nix` (or a `home.packages` line in `users/<u>/home.nix`) |
| Editor / dev tooling | `modules/home/{editor,dev}.nix` |
| GUI app / desktop shell | `modules/home/{apps,linux-desktop,hyprland,noctalia}.nix` |
| System-wide package or service | `modules/system/default.nix` (or `modules/system/darwin.nix`) |
| Mac-only package | `users/lbr/home-darwin.nix`, or Homebrew in `machines/macbook/configuration.nix` |
| Newer package than pinned nixpkgs | Overlay in `modules/system/default.nix`, cherry-picking from `inputs.nixpkgs-unstable` |
| New host | `machines/<host>/{configuration,hardware,secrets}.nix` + entry in `flake.nix` + host key in `secrets.nix` |

Adding a package: prefer one already in the pinned nixpkgs. Reach for the
`nixpkgs-unstable` overlay only when the pinned version is too old, and for
macOS prefer a Homebrew cask/brew when no aarch64-darwin Hydra build exists
(e.g. `witr`, `ghostty`, `sofka`).

## Secrets (agenix)

Two places must agree:

1. `secrets.nix` — the agenix recipients. Each secret lists the host public
   keys allowed to decrypt it.
2. `machines/<host>/secrets.nix` — declares `age.secrets.<name>` so it lands at
   `/run/agenix/<name>` after a rebuild (owner/mode set here).

To add a host to an existing secret, **rekey from a machine that can already
decrypt it** (rekeying needs the current plaintext access): fill the host key in
`secrets.nix`, comment out any still-placeholder keys, then `agenix -r`, commit,
pull on the target, `nh os switch .`. A key that is not a recipient simply
can't decrypt that file — see the commented `ssh-personal-homelab` block in
`machines/macbook/secrets.nix`. Never commit plaintext; the `.age` files are
safe to commit.

## Landmines — do not "fix" these

- **Omitted flake `follows` are deliberate.** `noctalia` (shell), `sofka`, and
  `nono#prebuilt` intentionally do *not* follow our nixpkgs: following it
  changes dependency hashes and misses upstream binary caches. `nono` also
  tracks `main` because its release-tag tarball hash is stale. Read the input
  comments in `flake.nix` before touching them.
- **macbook runs Determinate Nix** → `nix.enable = false`; nix-darwin must not
  manage `/etc/nix/nix.conf`. `nix-homebrew.autoMigrate` and
  `home-manager.backupFileExtension = "backup"` exist to let activation proceed
  over pre-existing files.
- **`homebrew.onActivation.cleanup = "zap"`** untaps/uninstalls anything not
  listed in `machines/macbook/configuration.nix`.
- **`hardware.nix` is generated.** Only replace the LUKS/boot UUIDs (see
  `install-physical.md`); don't restructure it.
- **Duplicate `modules/system/default.nix` import** (from both
  `lib/mksystem.nix` and each machine config) is harmless — the module system
  dedupes. Leave it.
- **`result` / `result-*` and `docs/superpowers/` are gitignored.** `result` is
  a build symlink.

## Conventions

- Conventional Commits (`feat(darwin): …`, `fix(system): …`), scoped by area.
- Keep each machine's `configuration.nix` thin — shared behavior belongs in
  `modules/`.
- Don't commit private data (real git email, passwords). The work git identity
  is set in `users/work/home.nix` as a placeholder, and `linus`'s email is set
  manually post-install.

## Verify before claiming done

Build the affected output (`nh os build .` / `nh os build .#<host>`), or at
minimum `nix flake check --no-build`. Never push; never run a destructive git
operation without explicit approval. Installation walkthroughs live in
`README.md`, `install-physical.md`, and `install-vm.md`.
